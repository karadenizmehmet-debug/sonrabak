# Sonra Bak

İnternette, Instagram'da, YouTube'da gördüğün içerikleri tek yerde kaydet, otomatik ya da elle kategorilere ayır, sonra kategoriler içinde gezip bul.

**Uygulama:** https://karadenizmehmet-debug.github.io/sonrabak/

## Özellikler
- Link veya metin yapıştırıp kaydetme
- Otomatik kategori (platform + anahtar kelime) veya elle seçim
- 🤖 Akıllı kategori: kendi Google Gemini (ücretsiz) veya Claude API anahtarınla. Anahtar yalnızca telefonda saklanır, repoya girmez.
- Düzelttikçe öğrenir: kategori değiştirdiğinde başlıktaki kelimeleri ve siteyi o kategoriye ekler
- YouTube/Vimeo linklerinde gerçek başlığı otomatik getirir
- Kategori ekleme, silme, sıralama, anahtar kelime düzenleme
- Arama, "Bakılmadı" ve yıldız filtresi
- Android'de telefonun **Paylaş** menüsünden doğrudan kaydetme (uygulama ana ekrana eklendiyse)
- Gece/gündüz modu, çevrimdışı çalışma
- JSON yedek indirme / yükleme

## Telefona kurma (Android, Chrome)
1. Uygulama linkini Chrome'da aç.
2. Menü (⋮) → **Ana ekrana ekle / Uygulamayı yükle**.
3. Artık Instagram, YouTube vb. içinde **Paylaş** dediğinde listede **Sonra Bak** çıkar.

Kayıtlar telefonun tarayıcısında (localStorage) saklanır. Düzenli olarak **Yedek indir** kullan.
